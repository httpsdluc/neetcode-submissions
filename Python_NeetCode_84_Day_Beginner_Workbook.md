1. Open the [Python coding sandbox](https://www.programiz.com/python-programming/online-compiler/) and keep it alongside this file.
2. Each day, click the **Python lesson** link, then the **NeetCode lesson** link(s). A lesson may be revisited across several days intentionally.
3. Follow **30 min Python → 40 min NeetCode → 40 min write code → 10 min review**.
4. **Type all code yourself.** Try exercises before reading solutions. After 20–25 minutes stuck, seek a hint, close it, and code without looking.
5. Mark a day complete only when you can explain its **exit check**. If not, repeat it tomorrow; the dates are suggestions, not penalties.
6. NeetCode indicates some lessons are free and others may require access. If locked, use its written materials if available or work on that day's Python task until you can access the lesson.
